# Acme Analytics — Vendor Self-Assessment Report

## Company Overview

Acme Analytics provides customer behavior analytics for enterprise retail
clients. This report is submitted as part of the vendor onboarding process
for evaluation against NexusIQ's security and procurement standards.

## Security Posture

Acme Analytics maintains SOC 2 Type II certification, renewed annually. All
customer data is encrypted at rest using AES-256 and in transit using TLS 1.3.

## Data Handling

Acme Analytics processes data in US-East and EU-West regions depending on
customer configuration. Sub-processors are disclosed in Appendix B of the
full report (not included here).
