# Security Policy (SP-102) — Version 1

**Status:** Superseded by Version 2. Retained for historical reference and to
exercise version-conflict handling in retrieval and policy analysis.
**Effective:** 2023-01-15
**Owner:** Security & Compliance

## Section 1: Data Handling and Residency

Vendor-processed customer data may be stored and processed in any region
that provides adequate technical and organizational safeguards, as
determined by the vendor's most recent SOC 2 Type II report. No specific
geographic restriction applies beyond this adequacy requirement.

## Section 2: Encryption

All customer data must be encrypted at rest using AES-256 or equivalent, and
in transit using TLS 1.2 or higher.

## Section 3: Incident Response

Vendors must notify NexusIQ of any confirmed data security incident within
72 hours of discovery.

## Section 4: Certification

Vendors must hold a current SOC 2 Type II certification, renewed at least
every 18 months.
